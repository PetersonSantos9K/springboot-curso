# Spring Boot — Estudos Práticos

Repositório dedicado à prática dos conteúdos do curso **Spring Boot Expert**. Aqui estão os projetos desenvolvidos durante os estudos, com foco na aplicação dos conceitos do ecossistema Spring e no desenvolvimento back-end com Java.

## Curso de Referência

- **Curso:** [Spring Boot Expert: JPA, REST, JWT, OAuth2 com Docker e AWS](https://www.udemy.com/course/spring-boot-expert/)
- **Instrutor:** Dougllas Sousa
- **Plataforma:** Udemy

## Tecnologias

As tecnologias e versões abaixo correspondem às configurações atuais dos projetos deste repositório.

- **Java:** 25
- **Spring Boot:** 4.1.1
- **Maven:** gerenciamento de dependências e build
- **Spring Data JPA:** persistência e acesso a dados

## Objetivo

Praticar e consolidar os conhecimentos em Java e Spring Boot por meio dos exemplos e exercícios propostos pelo professor, em um ambiente de aprendizado controlado. Posteriormente, aplicar os conceitos adquiridos no desenvolvimento de projetos pessoais, explorando soluções próprias e aprofundando os conhecimentos em desenvolvimento back-end.
